# Oasis Infobyte Data Analytics Internship - Project Portfolio

This document contains descriptions of the six projects completed during my 4-week Data Analytics internship at Oasis Infobyte.

---

## PROJECT 1: Exploratory Data Analysis (EDA) on Retail Sales Data
- Level: 1
- Goal: To perform EDA on retail sales data to uncover patterns, trends, and insights for business decisions.
- Key Tasks: Data loading, descriptive statistics, time series analysis, customer and product analysis, and visualization.
- Skills: Data cleaning, interpreting statistics, and data visualization.

## PROJECT 2: Customer Segmentation Analysis
- Level: 1
- Goal: Group e-commerce customers into distinct segments based on behavior and purchase patterns.
- Key Tasks: Data exploration, calculating average purchase value and frequency, and using clustering algorithms (K-means).
- Skills: Practical experience with clustering, data exploration, and visualization.

## PROJECT 3: Cleaning Data
- Level: 1
- Goal: Fix or remove incorrect, corrupted, duplicate, or incomplete data within a dataset to ensure reliability.
- Key Tasks: Missing data handling, duplicate removal, standardization, and outlier detection.
- Skills: Ensuring data integrity and reliability.

## PROJECT 4: Sentiment Analysis
- Level: 1
- Goal: Develop a model to classify text data sentiments (Positive, Negative, or Neutral).
- Key Tasks: Natural Language Processing (NLP), feature engineering, and implementing machine learning algorithms like Naive Bayes or SVM.
- Skills: Understanding and processing human language through NLP and ML.

## PROJECT 5: Predicting House Prices with Linear Regression
- Level: 2
- Goal: Build a predictive model using linear regression to estimate house prices.
- Key Tasks: Feature selection, model training with Scikit-Learn, and performance evaluation using R-squared and MSE.
- Skills: Linear regression concepts, model evaluation, and interpretation.

## PROJECT 6: Wine Quality Prediction
- Level: 2
- Goal: Predict wine quality based on chemical characteristics like density and acidity.
- Key Tasks: Using classifier models such as Random Forest, Stochastic Gradient Descent (SGD), and Support Vector Classifier (SVC).
- Skills: Utilizing diverse classifier models and data analysis libraries like Pandas and NumPy.

---

## Summary of Skills & Tools
- Tools: Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn), Jupyter Notebook.
- Key Concepts: EDA, Feature Engineering, Regression, Classification, NLP, and Clustering.
